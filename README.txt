This is a static website. The Send button opens the visitor's email app with an email to keziah.ramessar@gmail.com already prepared. To send directly from the page without opening an email app, connect a form provider or backend before publishing.

PUBLISHING
Upload index.html, style.css, script.js and the entire assets folder to any static hosting provider such as GitHub Pages, Netlify or Vercel.

GALLERY
